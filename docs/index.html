Active Directory MCP

Read-only directory lookups and guarded group exports for approved clients.

Quickstart →Configure a read-only bind account and trusted CA.Tool reference →Explore identity, group, and report operations.Safety →Protect personal data and the report download route.
At a glance
Use MCP tools for identity status, user and group searches, memberships, and bounded CSV group-member reports. The repository is example source code, not a production deployment recipe.

Request path: Authorized MCP client → private gateway → MCP service → LDAPS directory

Quickstart

  1. Copy .env.example to ignored .env; replace every placeholder privately.
  2. Set your LDAPS endpoints and actual directory bases; mount your trusted CA under certs/ without committing it.
  3. Use a dedicated least-privilege read-only bind account and keep TLS and hostname validation enabled.
  4. Review docker compose config locally (it may display secrets); build and test with approved synthetic records behind an authenticated gateway.
cp .env.example .env
# Replace placeholders privately; place your CA under certs/
docker compose config >/dev/null
docker compose build

Do not commit a real .env, private certificates, API keys or inventory.

Deployment

This repository is an example, not a production deployment recipe. Use private configuration, approved service accounts and an access-controlled network. Inspect the resolved Compose settings on the deployment host; they may contain secrets.

Do not publish the service listener directly. Build success alone does not verify backend connectivity, caller authorization or safe output. Start with approved synthetic data and a rollback plan.

Tools & integration

Identity tools include ad_preflight, ad_health_check, ad_check_identity_status and ad_search_users. Group tools include ad_search_groups, ad_get_group, ad_get_group_members, ad_get_user_memberships and ad_find_users_in_group.

ad_export_group_members_csv creates guarded reports. Review the server implementation for the report download route, TTL, and operational limits; treat download URLs as bearer-style secrets and downloaded CSVs as sensitive personal data.

Security

The example has no published host port, but a private Docker network is not caller authorization. Supply your own authenticated and authorized gateway, least-privilege account, attribute-scoping and retention controls. Do not expose identity records, exports or report URLs publicly.

Scope account privileges to the required reads and review returned data, error messages and logs before attaching AI clients.

Validation & troubleshooting

Use the documented prerequisites and offline tests before connecting to a real directory. Test caller-denial paths, TLS failures, scope bounds, report expiry, group queries, and error logging with approved test identities.

If a tool fails, check private configuration, container health, TLS trust, upstream reachability, caller authorization and the relevant backend permissions before broadening access. Avoid pasting secret-bearing Compose output into issues.
